#全局目标

1.术语库由知识卡片(.md文件)以及归类目录组成。

2.所有入库规则只参考当前文件，不要自行添加其他文档。



#重要指标

1.观测边界(人说的）：画面内文字、弹幕、评论区、作者自述都算观测；
   视频画面、攻略打法、养成建议、无器物/技法知识的纯梗不算。

2.提取边界：只要库中不存在就建卡——非专名、换语境仍成立、有一词多解。库中存在就进行追加，插入到首行。



#知识卡片

1.【定义】一张卡片对应一个"相对独立、不可再分的稳定术语"，
   存在的唯一理由是"一词多解"：同一术语在不同观测语境下指向不同。

2.【结构】元信息 + 一个表格，仅此两件：

- 元信息：文件头部 front-matter，只写 name以及别名， 不要自行添加其他字段。
- 表格两列：
  ① 在观测上下文中的含义——一行 = 一次观测中的一个语义，
     行首可加【语境标签】（如【器物】【行话】），不判史创；
  ② 出处——可追溯链接，史/创、时代、热度随出处自然携带。
- 动态生长：新观测带来新解释就加一行，不重写旧行、不合并近似行。

3.【大小】单卡上限 4KB，超了先拆义（把某几行拆成新卡），不压缩文字。
