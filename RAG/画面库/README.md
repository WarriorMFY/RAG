#全局目标

1.画面库由画面卡片(.md文件)以及归类目录组成。

2.所有入库规则只参考当前文件，不要自行添加其他文档。



#重要指标

1.观测边界(画面演的·静态)：单帧可见的形制、材质、颜色、纹样、尺寸、造型、光线、色调。
   动作、镜头运动、切点归序列库；弹幕、评论、画面内文字转录不作为依据。

2.提取边界：观测到一个可见物件/造型/色调，就建一张卡(或向已有卡追加行)；
   每行一个静态视觉属性，新属性加行。



#画面卡片

1.【定义】一张卡片对应一个可见对象，元信息+一个表格，仅此两件：

- 元信息：front-matter 只写 name；
- 表格两列：可见特征｜证据。
  行首【属性标签】(形制/材质/颜色/纹样/光线/组合)，一行=一个静态属性；
  证据列写视频链接+时间帧(如"封面"、"00:02")，不存图片文件。

2.【与序列库分工】同一对象两库各记一份，不是冗余：
   "长啥样"进画面卡，"什么时候出现/怎么运动"进序列卡行。

3.【动态生长】新观测补行按时间帧就近插入，不重写旧行、不合并近似行。
   看不清的写"待核"，不许编。
