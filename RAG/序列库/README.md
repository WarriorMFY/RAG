#全局目标

1.序列库由序列卡片(.md文件)以及归类目录组成。

2.所有入库规则只参考当前文件，不要自行添加其他文档。



#重要指标

1.观测边界(画面演的)：视频画面——构图、景别、机位/运镜、动作、光线、色彩、场景实物。
   画面内文字(字幕/UI/血条文字)不转录、不作为依据；弹幕、评论区、作者自述不算。

2.提取边界：以"随时间变化的对象"为单位，观测到什么就建卡(或向已有卡追加行)。
   "切点是行的分界"只对片段卡成立，其余卡型按各自"一行是什么"分界。



#序列卡片

0.【卡型】一切序列都是"某个量随时间的取值"，按"一行是什么"分六型，表头随型而定，不得混用：

| 卡型 | 一行是什么 | 表头 |
|---|---|---|
| 片段卡 | 一个镜头 | 时间码｜景别｜机位/运镜｜内容｜证据 |
| 事件卡 | 一个瞬时事件 | 时间码｜事件｜持续｜覆盖/位置｜证据 |
| 统计卡 | 一个区段 | 区段｜时长｜段内切点｜平均镜长｜节奏判断｜证据 |
| 贯穿卡 | 一个元素的一种状态 | 时间码｜状态｜形态/位置｜证据 |
| 速度卡 | 一段恒定速度的区间 | 起止｜播放速度｜持续｜画面痕迹｜证据 |
| 光线卡 | 一段光线相对恒定的区间 | 起止｜主光源/方向｜亮度·色温｜区间内变化｜证据 |

1.【定义】一张卡片对应一段连续片段(片段卡)、一类事件(事件卡)、一条节奏曲线(统计卡)或一个元素的跨时段状态(贯穿卡)；
   元信息 + 一个表格，仅此两件：

- 元信息：front-matter 只写 name(作品名·对象名)和来源(链接)；
- 表格：列数由卡型定，见上表。行按时间正序排列。

2.【片段卡】"内容"只写画面上演的，不写弹幕/评论语；"证据"记切点检测参数或核看帧文件名。

3.【事件卡】"持续"写时长，未测写"待核"；"覆盖/位置"写遮住了什么、在画面何处。

4.【统计卡】"段内切点"只计区段内部的切点，段界另注；平均镜长＝区段时长÷镜头数。
   含变速段时，时长须注明"成片"或"素材"，两者不可混比。

5.【速度卡】"画面痕迹"必填，写判断依据(重复帧检测/运动能量检测/引擎慢放特征)；
   速度区间可在镜头内部(镜头内变速)，也可跨镜头；未检出变速时如实建"全片匀速"行，负结果同样入库。

6.【光线卡】只记环境光/场景照明层面（天光、主光方向、明暗、色温）；招式与特效的瞬时发光（格挡白光、红光爆等）归事件卡，不在此重复记。
   拼接造成的光线跳变照样记行，"区间内变化"注明成因。全片无设计内光线变化时建"基底恒定"行，负结果同样入库。

7.【贯穿卡】按元素追踪，不受片段边界限制。跨拼剪点时是否同一实物无法确定，写"待核"。

8.【动态生长】同一卡新观测按时间码插入对应位置，不重写旧行、不合并相邻行。

9.【大小】单卡上限 8KB(时序表天然比术语卡长)，超了按片段或对象拆卡。
