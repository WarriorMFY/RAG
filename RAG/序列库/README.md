#全局目标

1.序列库由序列卡片(.md文件)以及归类目录组成。

2.所有入库规则只参考当前文件，不要自行添加其他文档。



#重要指标

1.观测边界(画面演的)：视频画面——构图、景别、机位/运镜、动作、光线、色彩、场景实物。
   画面内文字(字幕/UI/血条文字)不转录、不作为依据；弹幕、评论区、作者自述不算。

2.提取边界：连续镜头序列观测到一段，就建一张卡(或向已有卡追加行)；
   切点是行的分界，切点之间算一行。



#序列卡片

1.【定义】一张卡片对应一个作品的一个连续片段，元信息+一个表格，仅此两件：

- 元信息：front-matter 只写 name(作品名·片段名)和来源(链接)；
- 表格五列：时间码｜景别｜机位/运镜｜内容｜证据。
  行=一个镜头，按时间正序排列；"内容"只写画面上演的，
  不写弹幕/评论语；"证据"记切点检测参数或核看帧文件名。

2.【动态生长】同一片段新观测补行按时间码插入对应位置，不重写旧行、不合并相邻行。

3.【大小】单卡上限 8KB(时序表天然比术语卡长)，超了按片段拆卡。
