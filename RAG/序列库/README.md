#全局目标

1.序列库由序列卡片(.md文件)以及归类目录组成。

2.所有入库规则只参考当前文件，不要自行添加其他文档。



#重要指标

1.观测边界(画面演的)：视频画面——构图、景别、机位/运镜、动作、光线、色彩、场景实物。
   画面内文字(字幕/UI/血条文字)不转录、不作为依据；弹幕、评论区、作者自述不算。

2.提取边界：序列的抽象定义就是"变化"——一个因变量沿一个自变量的取值。以"一对变量"为单位建卡，观测到什么就建卡(或向已有卡追加行)。



#序列卡片

1.【结构】一张卡 = 元信息 + 一个两列表格，仅此两件：

- 元信息(front-matter)：`name`(作品名·因变量名)、`描述`(一段话)、`来源`(链接)；
- 表格：两列 `自变量｜因变量`，行按自变量正序。

2.【两列的定义】
   自变量＝沿什么变：时间码、区段、镜头序号、全片、空间位置；
   因变量＝变的是什么：景别、运镜、播放速度、光线、道具状态、事件有无、平均镜长。
   一行 = 一个自变量取值(或一段取值区间)下因变量的一个取值；相邻同值区间合并为一行。

3.【零点】自变量从 0 开始，卡内时间码一律是相对本卡的零点：
   - 全片卡：00:00＝片头；
   - 片段卡：00:00＝该段起点，原片绝对区间写进`描述`作溯源(如"原片 02:17.5–02:24.5")；
   - 需要指回原片某帧/某秒时，写"原片 02:19.0"这样带"原片"二字的标注，不带标注的时间码一律按卡内相对时间读；
   - 首行必须是 00:00(或用「全片」作单行)；首行之前因变量无取值的，补一行负结果(如"00:00–01:34 无特效")。

4.【单变量】一张卡只记一个因变量，不夹带别的变量：
   - 场景与器物(画面里有什么、长什么样、环境布置)→画面库，不进序列卡；
   - 镜头(景别、机位、运镜、推拉摇移)→景别卡/运镜卡，不写进动作卡、光线卡；
   - 瞬时光效(格挡白光、红光爆、UI 弹出、黑场)→事件卡，不写进景别卡/光线卡；
   - 切点密度与镜长→节奏卡，不写进景别卡。
   动作卡是独立的因变量域：只写身体怎么动(姿态、朝向、位移、手里拿什么、与对手的相对位置)，不写镜头怎么摆。
   同一段时间轴会在多张卡里重复出现——重复是对的，混装是错的：重复换来的是"一张卡只回答一个问题"。

5.【卡名=因变量名】如 `作品名·景别.md`、`作品名·速度.md`；同一作品同一因变量只有一张卡。
   目录按因变量域分(景别／运镜／动作／速度／光线／状态／事件／节奏)，有卡才建目录。

6.【描述】front-matter 的 `描述` 是一段话，四件事写在里面：这条序列怎么变(取值走向)、适合什么时候用、复刻要点、采集方式与不可测边界。
   逐行证据不再单列，统一收进描述；行内只在判断不了的地方写"待核"。

7.【待核】画面判不了的如实写"待核"(坛内是否有酒、是否同一实物、入黑是渐变还是瞬切)，写在因变量格内，不编。

8.【负结果入库】未检出变速写"全片 1.0x"，光线无变化写"基底恒定"，没有事件写"无"——"没有变化"本身是结论。
   负结果同样从 00:00 起，用来补首行之前的空白。

9.【动态生长】新观测按自变量顺序插入对应位置，不重写旧行；相邻同值区间可以合并成一行(两列制下一段恒定取值本就该是一行)。

10.【大小】单卡上限 8KB。超了按因变量拆卡(如景别+运镜)，不压缩事实。
