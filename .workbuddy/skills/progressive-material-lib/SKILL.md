# 渐进式披露网络素材库

## 何时触发

- 需要真实图像参考素材（做 PPT、设计稿、文档配图等）而手头没有现成素材。
- 用户直接要求查找、沉淀某个 B站视频的素材（封面、抽帧、肖像等）。

## 何时不触发

- 修改本仓库代码，或开发本仓库的工具本身。

## 渐进式披露浏览原则

- **目录即节点，可递归**：每层摘要 `.md` 与目录同名，认这一份即可，不要整树加载。
- **一层一步**：进目录先读同名 `.md`，再决定是否下钻。
- **先查命中再动手**：确认已缓存 → 直接读，零抓取；确认没有 → 才抓。
- **归并优先于新建**：同义实体并入既有目录并登记别名，不建分裂目录。
- **诚实**：真实接口取数，不硬造命中，不拿占位内容填空；抓不到就说抓不到。

## 细则在仓库里

| 想知道 | 去哪 |
|---|---|
| 纪律、环境与边界 | `library/library.md` |
| 工具用法、站点树形、踩坑 | `library/<站点>/<站点>.md` |
| 已缓存的数据 | `library/<站点>/` 目录树 |
