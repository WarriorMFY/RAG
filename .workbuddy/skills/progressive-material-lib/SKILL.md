# 渐进式披露网络素材库

一个可以逐层翻的素材环境：目录是节点，同名 `.md` 是路标，工具负责取数，判断留给你。

## 什么时候进来

- 手头没有现成图像素材（做 PPT、设计稿、文档配图）。
- 用户点名要找、沉淀某个 B站视频的封面、抽帧、肖像。
- 改本仓库代码或开发工具：这里没有你要的东西。

## 环境长什么样

- **每层一份同名摘要**：目录叫什么，旁边就有一份同名 `.md`，先说清这一层是什么、子项有哪些。整棵树可能很大，逐层读比一次拉全更省。
- **一层只认一份**：进一层，读它自己的 `.md`，就知道要不要再往下。
- **叶子带清单**：视频叶子目录里的 `<BVID>.md` 除元信息外，还记着已抓哪些素材、几张——不 `list` 也能判断命中。
- **同义不分裂**：既有实体装得下，就在它的摘要里登记别名；只放一条视频的新分组，通常不值得建。
- **取不到就说取不到**：真实接口取数，不硬造命中，不拿占位内容填空。

## 细则在仓库里

| 想知道 | 去哪 |
|---|---|
| 环境与边界（依赖、降级） | `library/library.md` |
| 工具用法、目录树规范、归位判据 | `library/<站点>/<站点>.md` |
| 已缓存什么（不动目录也能看） | `python scripts/fetch.py status`，或 `library/<站点>/` 目录树 |
