# 渐进式披露 · 网络素材仓库

外部平台素材的本地静态缓存库。**访问者是带需求的 LLM**：命中与否、是否抓取、如何归类，都由你自己判断；仓库只给目录、工具和纪律，不做决策。

---

## 层结构

```
library/
├── library.md    ← 本文件：仓库层摘要（站点无关）
├── <站点>/        ← 站点目录，摘要见 <站点>/<站点>.md
└── _inbox/       ← 抓取暂存区（未归类），归位后清空，不入库
```

**只写本级子目录**。站点内部结构、建库归并、工具用法，一律由 `<站点>/<站点>.md` 负责，本文不越层描述。

## 环境

- Python 3.12 + `httpx`；抽帧需系统 `ffmpeg`
- 浏览目录与判断命中用你自己的文件工具，仓库不为此提供脚本
- **降级**：工具未就绪时，直接列目录树判断命中与结构，纪律不依赖工具
